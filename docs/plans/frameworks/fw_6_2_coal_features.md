# Framework 6.2. Coal and mine features (scoped)

**Tier C.** Deferred.
**Evidence level.** (a) per feature class.

## 1. Problem and objective
Mine portals, subsidence and spoil heaps are legacy hazards. They also look like well features. Venango has little coal.

**Objective of the first step.** An inventory-to-imagery identity audit.

## 2. Gate before any build
A state mine inventory with known position error and completeness. Without it, no feature matching.

## 3. Minimum feasibility step
Pick an area with mine features (western Pennsylvania coal counties). Compare 50 inventory points to lidar and imagery by eye. Record identity, offset and completeness. Choose feature-specific matching tolerances.

## 4. What a full framework would add
A classifier for mine feature classes, a mutual-confusion test against well pits (with an uncertain class), and annotation of new classes.

## 5. Inputs, risks, resources
Inputs. State mine inventory (unverified), lidar. Risks. Position error, completeness. Resources. 12 hours for the audit.

## 6. Documentation updates
Audit doc, master plan. Share class design with 6.3.
